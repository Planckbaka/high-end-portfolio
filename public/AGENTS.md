# public

## Purpose
Static assets served directly by Next.js. Contains favicon files, project images, article images, resume PDF, and SVG icons.

## Key Files
| File | Description |
|------|-------------|
| `avatar.jpeg` | Profile/avatar image |
| `resume.pdf` | Downloadable resume |

## Subdirectories
| Directory | Purpose |
|-----------|---------|
| `Favicon Converter/` | Multi-size favicon files and webmanifest |
| `images/` | Project thumbnails and article images |

## For AI Agents

### Working In This Directory
- Project images (`project-1.svg` through `project-4.svg`) are referenced in `src/config/data.ts`
- Article images follow the pattern `images/articles/<article-slug>/`
- SVG assets (`file.svg`, `globe.svg`, `next.svg`, `vercel.svg`, `window.svg`) are Next.js defaults
