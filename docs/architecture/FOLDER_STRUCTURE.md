Folder map for the High-End Portfolio project. Per-directory intent is also
documented in each directory's `AGENTS.md`; this file is the repo-wide view.

## Key architectural facts

- **Fonts:** Space Grotesk (display) + JetBrains Mono (code/metadata) via
  `next/font`, self-hosted with `display: swap`. Body text is the system sans
  with Chinese fallbacks.
- **Theme tokens:** `--background #f7f6f2` light / `#191b19` dark (see
  `globals.css`); motion is CSS-only and scrolling is native — see
  [DESIGN_SYSTEM.md](./DESIGN_SYSTEM.md), which is the binding document.
- **No `loading.tsx` anywhere** — every page inlines its full content into
  static HTML so the site works without JavaScript.
- **Deployment:** `@opennextjs/cloudflare` builds to `.open-next/` and deploys
  to a single Cloudflare Worker (`npm run deploy` / verified `deploy:prod`).
